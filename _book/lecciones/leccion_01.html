1  Manejo de información.

La información que vemos cotidianamente está organizada en diferentes tipos y formatos:

  • Texto.
  • Números.
  • Hojas de cálculo.
  • Imágenes.
  • Audio.
  • etc.

La mayor parte de toda esta información está compuesta de texto y números (ASCII o binario).

En los ejemplos siguientes veremos como definir, manipular y almacenar números y textos.

1.1 Variables y funciones incorporadas.

Ejemplo 1.1: Índice de masa corporal.

El índice de masa corporal (IMC) asocia la masa (peso) con la talla de una persona. La fórmula para medir el IMC nació gracias al matemático, astrónomo y estadístico belga Lambert Adolphe Quetelet en 1832 y se define como sigue:

\[ \text{IMC} = \dfrac{\text{peso [kg]}}{(\text{estatura [m])}^2} \]

En Python es posible definir una variable (un nombre) para almacenar un valor. Por ejemplo, definamos una variable para almacenar el peso de una persona, checa Ejemplo 1.1:

peso = 87.7

Ahora, usemos la función incorporada (Built-in functions) print() para conocer el contenido de la variable peso:

print(peso)
87.7

Para conocer más acerca de la función print() podemos usar otra función incorporada llamada help():

help(print)

Usemos ahora la función incorporada type() para conocer el tipo de la variable:

type(peso)
float

Usemos la función incorporada id() para conocer la “dirección en memoria” de la variable:

id(peso)
2624841584112

Hagamos lo mismo para almacenar la información de la estatura de una persona:

estatura = 1.78
# Escribimos las tres instrucciones anteriores en una sola celda 
# y usamos print() en cada instrucción:
print(estatura)
print(type(estatura))
print(id(estatura))

<class 'float'>

Observaciones:

  • Las líneas que aparecen con un # al inicio son comentarios, es decir, el intérprete de Python no las ejecuta por lo que son útiles solamente para documentar las acciones del código.
  • En las últimas dos instrucciones estamos concatenando dos funciones incorporadas. Este tipo de funciones anidadas o composición de funciones es muy común en Python. Observa la Figura 1.1.

Cada función incorporada puede recibir más de un argumento y de tipos diferentes, por ejemplo:

print("Peso =", peso)
print("Estatura =", estatura)
# Ahora agregamos las unidades
print("Peso =", peso, "[kg]")
print("Estatura =", estatura, "[m]")

Recordemos que deseamos calcular el IMC:

\[ \text{IMC} = \dfrac{\text{peso [kg]}}{(\text{estatura [m])}^2} \]

# Calcular el IMC
IMC = peso / estatura**2
# ¿Cuál fuel el resultado de nuestro cálculo?
print("IMC =", IMC)
print(type(IMC))
print(id(IMC))

Los número complejos.

En matemáticas se definen los números complejos por una parte real y por una parte imaginaria, por ejemplo:

\[ c = 12 + 5j \] La parte real es \(12\) y la parte imaginaria es \(5j\). Observación: en matemáticas se usa \(i\) en vez de \(j\); aquí usamos \(j\) para ser compatibles con Python. Para definir un número complejo en Python hacemos lo siguiente:

complejo = 12 + 5j # La parte imaginaria lleva una j al final
complejo = 12 + 5j

print(type(complejo))
print(complejo)
<class 'complex'>
(12+5j)

3 Ejemplo 2. Cálculo del interés compuesto.

Es aquel que se va sumando al capital inicial y sobre el que se van generando nuevos intereses. El dinero, en este caso, tiene un efecto multiplicador porque los intereses producen nuevos intereses. La fórmula para calcular el interés compuesto es la siguiente:

\[ A = P (1 + \dfrac{r}{n})^{nt} \]

donde:

  • \(A\) = cantidad final
  • \(P\) = capital inicial
  • \(r\) = tasa de interés
  • \(n\) = número de veces que se ha aplicado el interés por periodo
  • \(t\) = número de periodos transcurridos

Vamos a calcular el interés compuesto con los siguientes datos:

  • \(t = 2\),
  • \(n = 12\),
  • \(P = 250,000\) y
  • \(r = 0.18\).
# Definición de las variables
t = 2
n = 12
P = 250_000 # formato de entero grande
r = 0.18
print(t, type(t), id(t))
print(n, type(n), id(n))
print(P, type(P), id(P))
print(r, type(r), id(r))

Ahora implementamos la fórmula del interés compuesto: \(A = P (1 + \dfrac{r}{n})^{nt}\)

# Deberías obtener A =  357375.70298225543
print("Cantidad final A = ", A)

4 Objetos y tipado dinámico.

Python es un lenguaje Orientado a Objetos.

  • Todo lo que definimos será un objeto de una clase determinada.
  • Python tiene definidas clases de las cuales es posible construir objetos.
  • Una clase define atributos y métodos para los objetos.

Veamos algunos ejemplos:

# Definimos el objeto '1' y le damos el nombre 'a'
a = 1
print(a, type(a), id(a))

Observa que el contenido del objeto a es 1 y el tipo es int.

# Ahora hagamos lo siguiente
b = a
print(a, type(a), id(a))
print(b, type(b), id(b))

¡Los objetos a y b son en realidad el mismo objeto!

Los operadores is y not también pueden ayudar a saber cuando dos objetos son el mismo:

b is a
b is not a
# ¿Qué sucederá ahora?
b = 5.0
print(a, type(a), id(a))
print(b, type(b), id(b))

Los objetos a y b son diferentes! También los tipos de a y b son diferentes.

Podemos usar la función incorporada isinstance() para comprobar de qué tipo son las variables:

isinstance(b, int)
isinstance(b, float)
# ¿y ahora?
b = 3 + 5j
print(a, type(a), id(a))
print(b, type(b), id(b))
b = "nuevo objeto"
print(a, type(a), id(a))
print(b, type(b), id(b))

Como puedes observar el tipo de b ha cambiado dependiendo de su contenido, esto es lo que se conoce como tipado dinámico.

4.1 Varios nombres para un mismo objeto:

Se pueden dar varios nombres a un objeto desde su creación como sigue:

c = b = a = 3.1416

print(a, type(a), id(a))
print(b, type(b), id(b))
print(c, type(c), id(c))
# Podemos eliminar uno de los nombres
del(b)
# Este genera un error porque ya no existe el nombre 'b'. 
print(b, type(b), id(b))
# Pero se puede acceder al objeto original con los otros nombres
print(a, type(a), id(a))
print(c, type(c), id(c))

4.2 Definición de varios objetos a la vez.

Se pueden inicializar varios objetos en una sola instrucción como sigue:

x, y, z = "la x", 3.1416, 5
print(x, type(x), id(x))
print(y, type(y), id(y))
print(z, type(z), id(z))

Observa que los objetos son diferentes.

4.3 Intercambio de valores entre objetos (swap).

Para intercambiar el valor de dos objetos se puede hacer lo siguiente.

Primero definimos dos objetos:

a = 1
b = 2
print("a = ", a, ", id = ", id(a))
print("b = ", b, ", id = ", id(b))

Ahora hacemos el intercambio de objetos usando una variable temporal:

temp = a
a = b
b = temp
print("a = ", a, ", id = ", id(a))
print("b = ", b, ", id = ", id(b))

Observa que el valor de los objetos fue intercambiado, a contiene lo que contenía b.

Pero es posible hacer esta operación en una sola instrucción como sigue:

a, b = b, a
print("a = ", a, ", id = ", id(a))
print("b = ", b, ", id = ", id(b))

4.4 Atributos y métodos.

Definimos tres objetos:

entero = 1
real = 1.1
complejo = 1 + 2j

Cada objeto tiene un conjunto de atributos y métodos los cuales dependen del tipo del objeto. Por ejemplo:

entero.as_integer_ratio()
real.as_integer_ratio()
complejo.real

4.5 Interacción entre objetos.

ratio = entero.as_integer_ratio()
print(ratio, type(ratio))
ratio.count(1)
entero.as_integer_ratio().count(1)

5 Ejemplo 3. Conjunto de Mandelbrot.

Romero Schmidtke, CC BY-SA 3.0, via Wikimedia Commons

Tomemos un punto de partida \(c\) en el plano complejo. Luego usamos la ecuación de recurrencia cuadrática

\[ \begin{cases} z_0 & = 0 \in \mathbb{C} \\ z_{n+1} & = z_{n}^2 + c \end{cases} \]

para obtener una secuencia de números complejos \(z_n\) con \(n=0, 1, 2,\dots\). Si esta sucesión queda acotada, entonces se dice que \(c\) pertenece al conjunto de Mandelbrot, y si no, queda excluido.

Ejemplo:

Datos iniciales: |Variable||Valor| |:–:|–|:–:| |\(c\)|=|\(j\)| |\(z_0\)|=|\(0\)|

# Valores iniciales
c = 1.0j
z0 = 0
print(c, z0)
1j 0

Relación de recurrencia:

Variable Operación Resultado
\(z_1\) = \(z_0^2 + c\) = \(0^2 + j\) = \(j\)
\(z_2\) = \(z_1^2 + c\) = \(j^2+j\) = \(−1+j\)
\(z_3\) = \(z_2^2 + c\) = \((−1+j)^2+j\) = \(−2j+j=−j\)
\(z_4\) = \(z_3^2 + c\) = \((−j)^2+j\) = \(−1+j\)
\(z_5\) = \(z_4^2 + c\) = \((−1+j)^2+j\) = \(−j\) 
# Implementamos la ecuación de recurrencia cuadrática
z1 = z0**2 + c
z2 = z1**2 + c
z3 = z2**2 + c
z4 = z3**2 + c
z5 = z4**2 + c

print(z1, z2, z3, z4, z5, sep="\n") 
1j
(-1+1j)
-1j
(-1+1j)
-1j

¿Cuál es el tipo de las variables \(z_n\) para \(n = 0, \dots 5\) ?

print(type(z0), type(z1), type(z2), type(z3), type(z4), type(z5), sep="\n")
<class 'int'>
<class 'complex'>
<class 'complex'>
<class 'complex'>
<class 'complex'>
<class 'complex'>

¿Cuál es el id de las variables \(z_n\) para \(n = 0, \dots 5\) ?

print(id(z0), id(z1), id(z2), id(z3), id(z4), id(z5), sep="\n")
